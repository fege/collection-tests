# TC-E2E-002: Webhook validation after migration — migrated notebook can be updated

**Objective**: End-to-end validation that after a successful migration from accelerator profile to hardware profile, the migrated notebook can be updated without webhook rejection — confirming the webhook correctly resolves the hardware profile in the annotated namespace.

**Preconditions**:
- OpenShift cluster with RHOAI 3.3 operator installed (migration completed)
- Notebook `e2e-test-workbench` in `e2e-migration-project` successfully migrated with both hardware profile annotations
- Hardware profile exists in `redhat-ods-applications` matching the annotation

**Test Steps**:
1. Verify the notebook has both hardware profile annotations:
   ```bash
   oc get notebook e2e-test-workbench -n e2e-migration-project \
     -o jsonpath='{.metadata.annotations.opendatahub\.io/hardware-profile-name}'
   oc get notebook e2e-test-workbench -n e2e-migration-project \
     -o jsonpath='{.metadata.annotations.opendatahub\.io/hardware-profile-namespace}'
   ```
2. Update the notebook (e.g., change an environment variable) to trigger webhook validation:
   ```bash
   oc patch notebook e2e-test-workbench -n e2e-migration-project \
     --type merge -p '{"spec":{"template":{"spec":{"containers":[{"name":"notebook","env":[{"name":"E2E_TEST","value":"webhook-validation"}]}]}}}}'
   ```
3. Verify the update was accepted by the webhook:
   ```bash
   oc get notebook e2e-test-workbench -n e2e-migration-project \
     -o jsonpath='{.spec.template.spec.containers[0].env}' | grep "E2E_TEST"
   ```
4. Check webhook logs for any rejection attempts:
   ```bash
   oc logs -l name=rhods-operator -n redhat-ods-operator --tail=50 | grep -i "webhook.*reject\|not found.*namespace"
   ```

**Expected Results**:
- The notebook update is accepted by the webhook without errors
- The webhook correctly resolves the hardware profile in `redhat-ods-applications` (not in `e2e-migration-project`)
- No "not found in namespace" errors in webhook logs
- The updated notebook retains both hardware profile annotations
