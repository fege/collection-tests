# TC-E2E-003: Multiple notebooks with different accelerator profiles all migrate correctly

**Objective**: End-to-end validation that multiple notebooks across different namespaces, each using different accelerator profiles, all migrate successfully in a single operator upgrade cycle.

**Preconditions**:
- OpenShift cluster with RHOAI operator installed (pre-upgrade version)
- Accelerator profile `e2e-accel-gpu` in `redhat-ods-applications`
- Accelerator profile `e2e-accel-tpu` in `redhat-ods-applications`
- Notebook `e2e-notebook-gpu` in `e2e-project-alpha` using `e2e-accel-gpu`
- Notebook `e2e-notebook-tpu` in `e2e-project-beta` using `e2e-accel-tpu`

**Test Steps**:
1. Verify both notebooks have accelerator profile references before migration:
   ```bash
   oc get notebook e2e-notebook-gpu -n e2e-project-alpha -o jsonpath='{.metadata.annotations}'
   oc get notebook e2e-notebook-tpu -n e2e-project-beta -o jsonpath='{.metadata.annotations}'
   ```
2. Trigger the operator upgrade to RHOAI 3.3
3. Wait for migration to complete (operator Running, no restarts)
4. Verify notebook `e2e-notebook-gpu` has both annotations:
   ```bash
   oc get notebook e2e-notebook-gpu -n e2e-project-alpha \
     -o jsonpath='{.metadata.annotations.opendatahub\.io/hardware-profile-name}'
   oc get notebook e2e-notebook-gpu -n e2e-project-alpha \
     -o jsonpath='{.metadata.annotations.opendatahub\.io/hardware-profile-namespace}'
   ```
5. Verify notebook `e2e-notebook-tpu` has both annotations:
   ```bash
   oc get notebook e2e-notebook-tpu -n e2e-project-beta \
     -o jsonpath='{.metadata.annotations.opendatahub\.io/hardware-profile-name}'
   oc get notebook e2e-notebook-tpu -n e2e-project-beta \
     -o jsonpath='{.metadata.annotations.opendatahub\.io/hardware-profile-namespace}'
   ```
6. Verify both hardware profiles were created in global namespace:
   ```bash
   oc get hardwareprofile -n redhat-ods-applications | grep "e2e-accel"
   ```
7. Verify both namespace annotations point to `redhat-ods-applications`:
   ```bash
   for ns in e2e-project-alpha e2e-project-beta; do
     for nb in e2e-notebook-gpu e2e-notebook-tpu; do
       NAMESPACE=$(oc get notebook $nb -n $ns \
         -o jsonpath='{.metadata.annotations.opendatahub\.io/hardware-profile-namespace}' 2>/dev/null)
       [ -n "$NAMESPACE" ] && echo "$nb in $ns: namespace=$NAMESPACE"
     done
   done
   ```

**Expected Results**:
- Both notebooks have `opendatahub.io/hardware-profile-name` and `opendatahub.io/hardware-profile-namespace` annotations
- Both namespace annotations point to `redhat-ods-applications`
- Two distinct hardware profiles were created in `redhat-ods-applications`
- Operator completed migration without crashloop
- Notebooks across different namespaces are all migrated correctly
