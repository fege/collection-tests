# TC-E2E-001: Deploy EvalHub → ServiceMonitor created → Prometheus scrapes → metrics queryable

**Objective**: Validate the complete happy path: deploying an EvalHub instance results in automatic ServiceMonitor creation, Prometheus discovery and scraping, and metrics being queryable via the monitoring stack.

**Preconditions**:
- OpenShift cluster with RHOAI 3.5.EA1 and TrustyAI operator
- User-workload-monitoring enabled (`enableUserWorkload: true`)
- `monitoring.coreos.com/v1` CRD available
- No existing EvalHub instances in the test namespace

**Test Steps**:
1. Deploy an EvalHub CR with metrics enabled
   ```bash
   oc apply -f evalhub-metrics-enabled.yaml -n opendatahub
   ```
2. Verify the EvalHub pods are running
   ```bash
   oc wait --for=condition=Ready pod -l app=evalhub -n opendatahub --timeout=120s
   ```
3. Verify a ServiceMonitor is created in the same namespace with correct spec
   ```bash
   oc get servicemonitor -n opendatahub -l app=evalhub -o jsonpath='{.items[0].spec.endpoints[0].path}'
   ```
4. Verify the ServiceMonitor has an ownerReference to the EvalHub CR
   ```bash
   oc get servicemonitor -n opendatahub -l app=evalhub -o jsonpath='{.items[0].metadata.ownerReferences[0].kind}'
   ```
5. Wait for Prometheus to discover and scrape the target (up to 90 seconds)
6. Verify the EvalHub scrape target is UP
   ```bash
   oc exec -n openshift-user-workload-monitoring prometheus-user-workload-0 -c prometheus -- \
     curl -s 'http://localhost:9090/api/v1/targets' | jq '.data.activeTargets[] | select(.labels.job | contains("evalhub")) | .health'
   ```
7. Query for EvalHub metrics
   ```bash
   oc exec -n openshift-user-workload-monitoring prometheus-user-workload-0 -c prometheus -- \
     curl -s 'http://localhost:9090/api/v1/query?query=up{job=~".*evalhub.*"}'
   ```

**Expected Results**:
- EvalHub pods are running and healthy
- ServiceMonitor is auto-created with correct spec (HTTPS, `/metrics`, 30s, ownerReference)
- Prometheus discovers EvalHub as an active target with state `UP`
- EvalHub metrics are queryable via the Prometheus API
