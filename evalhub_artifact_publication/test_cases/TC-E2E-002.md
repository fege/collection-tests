# TC-E2E-002: Partial artifact failure end-to-end with CompleteWithWarnings

**Objective**: Validate the complete failure-path user journey: evaluation succeeds, some artifact uploads fail, job status shows CompleteWithWarnings with per-artifact outcomes.

**Preconditions**:
- Full EvalHub deployment (server v0.3.0, SDK v0.1.5, MLflow v3.10.1+rhaiv.1, sidecar)
- Fault injection proxy to fail specific artifact uploads

**Test Steps**:
1. Configure fault injection to fail uploads for 1 of 3 artifacts
2. Submit an evaluation job via the EvalHub API with MLflow tracking enabled
3. Wait for job status to reach a terminal state
4. Verify job status is `CompleteWithWarnings`
5. Verify `artifact_uris` contains 3 entries: 2 with `status: success`, 1 with `status: failed`
6. Verify the failed artifact has an `error` field with meaningful error description
7. Retrieve the 2 successful artifacts via GET /get-artifact and verify they are valid
8. Verify the status event payload (POST /events) correctly transmitted the failure metadata

**Expected Results**:
- Job does not fail — evaluation result is preserved
- Partial failure is clearly distinguishable from full success
- Successful artifacts are still accessible
- Error details are actionable for troubleshooting
