# TC-E2E-006: Response format matches OpenAI-compatible schema across all models

**Objective**: Verify that the tool calling response from each in-scope model conforms to the OpenAI-compatible chat completion schema, ensuring interoperability with standard client libraries.

**Test Steps**:
1. For each in-scope model, deploy using the `servingConfig.toolCalling` values
2. Wait for vLLM to reach ready state (verify via `GET /v1/models`)
3. Send a tool calling request:
   ```json
   {
     "model": "<model-name>",
     "messages": [{"role": "user", "content": "What is the weather in Boston today?"}],
     "tools": [{"type": "function", "function": {"name": "get_weather", "description": "Get the current weather for a location", "parameters": {"type": "object", "properties": {"location": {"type": "string"}}, "required": ["location"]}}}],
     "tool_choice": "auto"
   }
   ```
4. Validate the response structure:
   - `choices[0].message.tool_calls` is a non-empty array
   - Each tool call has `id` (string), `type` = `"function"`, and `function` object
   - `function.name` is a string matching one of the provided tool names
   - `function.arguments` is a valid JSON string
   - `choices[0].finish_reason` is `"tool_calls"`
5. Repeat for all in-scope models

**Expected Results**:
- All models return responses conforming to the OpenAI-compatible chat completion schema
- `tool_calls` array is present and non-empty for each model
- `finish_reason` is `"tool_calls"` for each model
- `function.arguments` is parseable JSON for each model
- No model-specific deviations from the standard schema
