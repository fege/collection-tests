# TC-E2E-006: Verify tool calling response format matches OpenAI-compatible schema across all models

**Objective**: Confirm that every in-scope model, when served with the validated configuration, produces tool calling responses that conform to the OpenAI-compatible response schema.

**Preconditions**:
- At least one in-scope model is deployed with its validated configuration

**Test Steps**:
1. For each in-scope model deployed with validated tool calling configuration, send a tool calling request via `POST /v1/chat/completions`
2. Validate the response structure against the OpenAI tool calling schema:
   - `choices[0].message.role` == `"assistant"`
   - `choices[0].message.tool_calls` is a non-empty array
   - Each entry in `tool_calls` has: `id` (string), `type` == `"function"`, `function.name` (string), `function.arguments` (valid JSON string)
   - `choices[0].finish_reason` == `"tool_calls"`
3. Validate that `function.arguments` can be parsed as JSON and matches the tool's parameter schema

**Expected Results**:
- All in-scope models produce responses conforming to the OpenAI-compatible tool calling schema
- `tool_calls` entries have valid `id`, `type`, `function.name`, and `function.arguments` fields
- `function.arguments` is valid JSON (not raw text, not malformed)
- No model-specific deviations from the standard response format
