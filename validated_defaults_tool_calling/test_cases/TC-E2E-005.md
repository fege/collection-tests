# TC-E2E-005: Full tool calling round-trip with Llama-3.3-70B-Instruct

**Objective**: Validate the complete user journey: read the model card, copy-paste the vllm serve command, deploy the model, and execute a successful tool calling round-trip with Llama-3.3-70B-Instruct.

**Preconditions**:
- Llama-3.3-70B-Instruct model weights are available on storage
- GPU hardware meets minimum requirements: 2x A100 80GB (160 GB total VRAM)
- Red Hat AI Inference Server version matches the version documented in the model card

**Test Steps**:
1. Open the Llama-3.3-70B-Instruct model card from the model-metadata-collection repository
2. Locate the "Tool Calling Configuration" section
3. Copy the documented `vllm serve` command
4. Deploy the model using the copy-pasted command
5. Wait for vLLM to reach ready state (verify via `GET /v1/models`)
6. Send a tool calling request:
   ```json
   {
     "model": "Llama-3.3-70B-Instruct",
     "messages": [{"role": "user", "content": "Look up the stock price of NVIDIA"}],
     "tools": [
       {
         "type": "function",
         "function": {
           "name": "get_stock_price",
           "description": "Get the current stock price for a given ticker symbol",
           "parameters": {"type": "object", "properties": {"ticker": {"type": "string", "description": "Stock ticker symbol (e.g., NVDA)"}}, "required": ["ticker"]}
         }
       }
     ],
     "tool_choice": "auto"
   }
   ```
7. Validate the response contains a valid `tool_calls` array with `function.name` = `get_stock_price`
8. Submit a tool result and verify the model produces a coherent natural language response

**Expected Results**:
- vLLM starts with the documented command on 2x A100 80GB
- Tool calling request returns valid `tool_calls` with `ticker` argument set to `"NVDA"` or equivalent
- `finish_reason` is `"tool_calls"`
- Full round-trip completes with model incorporating stock price data in response
- No parsing errors or empty `tool_calls` arrays
