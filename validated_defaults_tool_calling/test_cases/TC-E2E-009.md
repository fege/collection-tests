# TC-E2E-009: Catalog API to vLLM deployment end-to-end

**Objective**: Validate the full end-to-end flow from querying the catalog API for a model's `servingConfig.toolCalling` to deploying vLLM and completing a successful tool calling round-trip.

**Preconditions**:
- Catalog API is deployed and accessible
- At least one in-scope model exists in the catalog with `servingConfig.toolCalling` populated
- Model weights are available on storage accessible from the cluster
- GPU hardware meets minimum requirements

**Test Steps**:
1. Query the catalog API for a model that has `servingConfig.toolCalling`:
   ```
   GET /api/v1/models/<model-id>
   ```
2. Extract `servingConfig.toolCalling` fields from the API response:
   - `toolCallParser`
   - `chatTemplate`
   - `enableAutoToolChoice`
   - `requiredArgs` (if present)
3. Construct the `vllm serve` command from the extracted fields:
   ```bash
   vllm serve <model-path> \
     --tool-call-parser=<toolCallParser> \
     --chat-template=<chatTemplate> \
     --enable-auto-tool-choice \
     <requiredArgs if present>
   ```
4. Deploy the model using the constructed command
5. Wait for vLLM to reach ready state (verify via `GET /v1/models`)
6. Send a tool calling request:
   ```json
   {
     "model": "<model-name>",
     "messages": [{"role": "user", "content": "What is the weather in Boston today?"}],
     "tools": [{"type": "function", "function": {"name": "get_weather", "description": "Get the current weather for a location", "parameters": {"type": "object", "properties": {"location": {"type": "string"}}, "required": ["location"]}}}],
     "tool_choice": "auto"
   }
   ```
7. Validate the response contains a valid `tool_calls` array
8. Submit the tool result and verify natural language continuation

**Expected Results**:
- Catalog API returns `servingConfig.toolCalling` with all expected fields populated
- The `vllm serve` command constructed from API data executes successfully
- Tool calling round-trip completes with valid `tool_calls` and coherent model response
- No manual intervention or undocumented configuration is needed between API query and successful deployment
