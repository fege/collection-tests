# TC-E2E-007: Verify multi-tool selection scenario

**Objective**: Confirm that a model served with the validated configuration can correctly select among multiple available tools when the user prompt matches one specific tool.

**Preconditions**:
- At least one in-scope model is deployed with its validated configuration

**Test Steps**:
1. Send a tool calling request with multiple tool definitions:
   ```json
   {
     "model": "<model-name>",
     "messages": [{"role": "user", "content": "What is the weather in Boston today?"}],
     "tools": [
       {
         "type": "function",
         "function": {
           "name": "get_weather",
           "description": "Get the current weather for a location",
           "parameters": {"type": "object", "properties": {"location": {"type": "string"}}, "required": ["location"]}
         }
       },
       {
         "type": "function",
         "function": {
           "name": "search_web",
           "description": "Search the web for information",
           "parameters": {"type": "object", "properties": {"query": {"type": "string"}}, "required": ["query"]}
         }
       },
       {
         "type": "function",
         "function": {
           "name": "calculate",
           "description": "Perform a mathematical calculation",
           "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}
         }
       }
     ],
     "tool_choice": "auto"
   }
   ```
2. Verify the model selects `get_weather` (the semantically correct tool for a weather query)
3. Verify the `tool_calls` array contains exactly one entry (not all three tools)

**Expected Results**:
- The model selects the semantically appropriate tool (`get_weather`) from the available options
- `tool_calls` array contains one entry with `function.name` == `get_weather`
- `function.arguments` contains a valid `location` value
- The model does not call irrelevant tools (`search_web`, `calculate`)
