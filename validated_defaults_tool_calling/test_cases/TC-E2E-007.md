# TC-E2E-007: Multi-tool selection scenario

**Objective**: Verify that in-scope models can correctly select the appropriate tool when multiple tools are available in a single request.

**Preconditions**:
- At least one in-scope model is deployed with its `servingConfig.toolCalling` values

**Test Steps**:
1. Deploy one in-scope model using its `servingConfig.toolCalling` values
2. Wait for vLLM to reach ready state (verify via `GET /v1/models`)
3. Send a request with 3 tools defined:
   ```json
   {
     "model": "<model-name>",
     "messages": [{"role": "user", "content": "What is the weather in Boston today?"}],
     "tools": [
       {"type": "function", "function": {"name": "get_weather", "description": "Get the current weather for a location", "parameters": {"type": "object", "properties": {"location": {"type": "string"}}, "required": ["location"]}}},
       {"type": "function", "function": {"name": "search_web", "description": "Search the web for information", "parameters": {"type": "object", "properties": {"query": {"type": "string"}}, "required": ["query"]}}},
       {"type": "function", "function": {"name": "calculate", "description": "Perform a mathematical calculation", "parameters": {"type": "object", "properties": {"expression": {"type": "string"}}, "required": ["expression"]}}}
     ],
     "tool_choice": "auto"
   }
   ```
4. Verify the model selects `get_weather` (the correct tool for the weather query)
5. Verify the model does NOT select `search_web` or `calculate`

**Expected Results**:
- The model selects exactly `get_weather` from the three available tools
- `function.arguments` contains a valid JSON string with `location` populated
- `finish_reason` is `"tool_calls"`
- The model demonstrates correct tool discrimination (does not hallucinate calls to irrelevant tools)
