# TC-E2E-004: Full tool calling round-trip with mistralai/Mistral-Small-4-119B-2603

**Objective**: Validate the complete user journey: read the model card, copy-paste the vllm serve command, deploy the model, and execute a successful tool calling round-trip with Mistral-Small-4-119B.

**Preconditions**:
- mistralai/Mistral-Small-4-119B-2603 model weights are available on storage
- GPU hardware meets minimum requirements (A100 80GB or H100 80GB, count TBD per PSAP docs)
- Red Hat AI Inference Server version matches the version documented in the model card

**Test Steps**:
1. Open the Mistral-Small-4-119B model card from the model-metadata-collection repository
2. Locate the "Tool Calling Configuration" section
3. Copy the documented `vllm serve` command
4. Deploy the model using the copy-pasted command
5. Wait for vLLM to reach ready state (verify via `GET /v1/models`)
6. Send a tool calling request:
   ```json
   {
     "model": "mistralai/Mistral-Small-4-119B-2603",
     "messages": [{"role": "user", "content": "Create a calendar event for tomorrow at 2pm titled 'Team standup'"}],
     "tools": [
       {
         "type": "function",
         "function": {
           "name": "create_event",
           "description": "Create a calendar event",
           "parameters": {"type": "object", "properties": {"title": {"type": "string"}, "date": {"type": "string", "description": "Date in YYYY-MM-DD format"}, "time": {"type": "string", "description": "Time in HH:MM format"}}, "required": ["title", "date", "time"]}
         }
       }
     ],
     "tool_choice": "auto"
   }
   ```
7. Validate the response contains a valid `tool_calls` array
8. Complete the round-trip with a tool result and verify coherent response

**Expected Results**:
- vLLM starts with the documented command using the Mistral-specific parser
- Tool calling request returns valid `tool_calls` with correct function and parseable arguments
- Full round-trip completes successfully
- Parser correctly handles Mistral's tool calling output format
