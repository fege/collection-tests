# TC-PROC-001: Verify model-metadata-collection repo contains documented process for adding new configs

**Objective**: Confirm that the model-metadata-collection repository includes a documented process for adding validated tool calling configurations for new models, as required by Acceptance Criteria #4.

**Test Steps**:
1. Access the model-metadata-collection repository
2. Search for documentation covering the process of adding a new model's tool calling configuration (e.g., CONTRIBUTING.md, README.md, or a dedicated process doc)
3. Verify the documentation covers:
   - Where to add the configuration (which file, which section)
   - What format to use for the configuration data
   - What validation steps are required before merging
   - Who reviews and approves new configurations
4. Verify the documentation is accessible from the repository root (linked from README or discoverable)

**Expected Results**:
- A documented process exists for adding validated tool calling configurations for new models
- The process covers location, format, validation requirements, and approval workflow
- The documentation is discoverable from the repository root
