# TC-E2E-003: Full tool calling round-trip with nvidia/NVIDIA-Nemotron-3-Super-120B-A12B-NVFP4

**Objective**: Validate the complete user journey: read the model card, copy-paste the vllm serve command, deploy the model, and execute a successful tool calling round-trip with Nemotron-3-Super-120B.

**Preconditions**:
- nvidia/NVIDIA-Nemotron-3-Super-120B-A12B-NVFP4 model weights are available on storage
- GPU hardware meets minimum requirements (H100 80GB, count TBD per PSAP docs)
- Red Hat AI Inference Server version matches the version documented in the model card

**Test Steps**:
1. Open the Nemotron-3-Super-120B model card from the model-metadata-collection repository
2. Locate the "Tool Calling Configuration" section
3. Copy the documented `vllm serve` command
4. Deploy the model using the copy-pasted command
5. Wait for vLLM to reach ready state (verify via `GET /v1/models`)
6. Send a tool calling request:
   ```json
   {
     "model": "nvidia/NVIDIA-Nemotron-3-Super-120B-A12B-NVFP4",
     "messages": [{"role": "user", "content": "Search for recent papers about transformer architectures"}],
     "tools": [
       {
         "type": "function",
         "function": {
           "name": "search_papers",
           "description": "Search for academic papers by topic",
           "parameters": {"type": "object", "properties": {"query": {"type": "string"}, "max_results": {"type": "integer", "default": 5}}, "required": ["query"]}
         }
       }
     ],
     "tool_choice": "auto"
   }
   ```
7. Validate the response contains a valid `tool_calls` array
8. Complete the round-trip with a tool result and verify coherent response

**Expected Results**:
- vLLM starts with the documented command (NVFP4 quantization loads correctly)
- Tool calling request returns valid `tool_calls` with correct function and parseable arguments
- MoE architecture (12B active parameters) does not interfere with tool calling parsing
- Full round-trip completes successfully
