# TC-E2E-008: Tool calling with streaming enabled

**Objective**: Verify that tool calling works correctly when streaming is enabled, and that streamed chunks assemble into a valid `tool_calls` response.

**Preconditions**:
- At least one in-scope model is deployed with its `servingConfig.toolCalling` values

**Test Steps**:
1. Deploy one in-scope model using its `servingConfig.toolCalling` values
2. Wait for vLLM to reach ready state (verify via `GET /v1/models`)
3. Send a tool calling request with `stream: true`:
   ```json
   {
     "model": "<model-name>",
     "messages": [{"role": "user", "content": "What is the weather in Boston today?"}],
     "tools": [{"type": "function", "function": {"name": "get_weather", "description": "Get the current weather for a location", "parameters": {"type": "object", "properties": {"location": {"type": "string"}}, "required": ["location"]}}}],
     "tool_choice": "auto",
     "stream": true
   }
   ```
4. Collect all SSE chunks from the streamed response
5. Assemble the `tool_calls` from the streamed delta chunks
6. Verify the assembled result matches the expected tool call structure

**Expected Results**:
- Streamed chunks are received without errors or connection drops
- Assembled `tool_calls` contain `function.name` = `get_weather` and valid JSON `arguments`
- The final chunk has `finish_reason` = `"tool_calls"`
- The assembled streamed response is equivalent to a non-streamed response for the same request
